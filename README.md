# STY Browser

Windows 桌面浏览器第一版项目。

## 当前功能

- 标签页
- 地址栏
- 网页访问
- 后退 / 前进 / 刷新
- 下载到 Windows 默认下载目录
- 开发者工具（F12）
- 新建 / 关闭标签页
- 地址栏搜索

## 环境

建议：

- Windows 10/11
- Node.js 20+
- npm

## 运行

```bash
npm install
npm start
```

## 打包 Windows 安装程序

```bash
npm run build
```

生成的安装文件通常会出现在 `dist/`。
