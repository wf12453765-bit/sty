# STY Browser v0.3.0

Windows 桌面浏览器第三版。

## 功能
- 多标签页
- 地址栏与搜索
- 后退 / 前进 / 刷新
- 自定义新标签页
- 收藏夹
- 历史记录
- 下载管理与下载进度
- 设置页面
- 开发者工具 F12
- 常用快捷键
- Windows NSIS 安装包配置
- 本地数据持久化

## 安装开发环境
Windows 10/11 + Node.js 20+

## 运行
npm install
npm start

## 打包
npm run build

## 注意
首次运行 `npm install` 会从 npm 下载 Electron 和 electron-builder。
